План останнього виправлення:

1. Прибрати Google-авторизацію з інтерфейсу
- Видалити кнопку “Продовжити з Google” зі сторінки входу/реєстрації.
- Прибрати розділювач “або”, якщо після цього лишається тільки email/password.
- Залишити чистий вхід і реєстрацію через email/password.

2. Прибрати Google-flow з коду застосунку
- Видалити функцію `signInGoogle` з auth helpers.
- Прибрати імпорт/виклик Google OAuth зі сторінки авторизації.
- Прибрати GoogleIcon, якщо він більше ніде не використовується.

3. Відв’язати застосунок від Lovable OAuth-коду
- Перевірити, чи `@lovable.dev/cloud-auth-js` та `src/integrations/lovable` більше ніде не використовуються.
- Якщо використання лишається тільки для Google — прибрати залежність і файл інтеграції.
- Не чіпати твій існуючий Supabase-клієнт, Gemini, новини, дашборд або інші частини застосунку.

4. Перевірка
- Переконатися пошуком по коду, що немає згадок `Google`, `signInWithOAuth`, `lovable.auth`, `cloud-auth-js` у робочому auth-flow.
- Перевірити сторінку `/auth`: має лишитися тільки email/password вхід і реєстрація без Google-кнопки.
